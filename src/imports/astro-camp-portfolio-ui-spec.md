## プロンプト本文

以下の要件に基づいて、宇宙人材育成イベント「AstroCamp 2026」の参加者ポートフォリオサイトのUIデザインを作成してください。

---

### 1. サイトの目的と背景

このサイトは「AstroCamp 2026」という宇宙産業人材育成合宿の参加者ポートフォリオプラットフォームです。3つの目的があります：

1. **参加者の成長の可視化**: 参加前→参加中→参加後のスキル・価値観の変化を縦断的に記録・表示する
2. **協賛企業と参加者のマッチング**: 企業が参加者の能力・活動を把握し、インターン・採用につなげる（現状マッチング率20%→目標50%）
3. **参加者同士のネットワーキング**: 同じ志を持つ学生の交流促進

ターゲットユーザーは宇宙工学系の大学生・大学院生（20〜25歳）と、宇宙系スタートアップ・メーカーの採用担当者です。

---

### 2. ユーザー種別と画面構成

3種類のユーザーがおり、それぞれ専用のダッシュボードを持ちます：

#### A. 参加者（メインユーザー）
- 自分のポートフォリオ編集
- 他の参加者の公開情報閲覧
- 設定（公開範囲の制御）

#### B. 協賛企業
- 参加者一覧の閲覧（検索・フィルタ付き）
- 個別ポートフォリオ閲覧
- 「気になる」ブックマーク機能
- ブックマークリスト管理

#### C. 運営スタッフ
- 参加者管理
- 企業アカウント管理
- サイト設定

---

### 3. ページ一覧と遷移

```
ログインページ（Google認証 + メール/パスワード）
├── 参加者ログイン → 参加者一覧（ホーム）
│   ├── 他の参加者プロフィール（閲覧のみ）
│   └── マイページ（編集可能）
├── 企業ログイン → 企業ダッシュボード（ホーム）
│   ├── 参加者一覧（検索・フィルタ付き）
│   ├── 参加者プロフィール（閲覧 + ブックマーク）
│   └── ブックマークリスト
└── 運営ログイン → 管理画面
```

---

### 4. 参加者プロフィールページの掲載項目（最重要ページ）

このページがサイトの核です。以下のセクションを上から順に配置してください：

#### ヘッダー部
- 顔写真（丸型アバター）
- 氏名
- 所属大学・学部・学年
- 自己紹介文（200字程度）

#### 興味分野・スキル（タグ表示）
- 興味分野タグ（例: 熱制御工学、軌道力学、ADCS、推進系）
- 技術スキルタグ（例: Python, MATLAB, SolidWorks, C++）

#### 経歴セクション
- タイムライン形式で学歴・活動歴を表示

#### 志向・キャリア意向セクション（企業にとって最重要）
- 「今やりたいと思ってること」（自由記述テキスト）
- 「インターン/宇宙産業就職への興味」（3段階: 興味あり / 検討中 / 今は考えていない + コメント欄）
- 将来の目標（任意）

#### AstroCamp活動セクション（成長の可視化 = サイトの差別化ポイント）
- 参加プログラム・ワークショップ名
- **参加前の意気込み**と**参加後の心境の変化**を並列表示（Before/After形式）
- 活動成果（写真・スライド添付可能）

#### スキル成長マトリクス（数値の可視化）
- 進捗報告力、質問の的確性、レビュー受容度、改善実行速度などを5段階でレーダーチャートまたはプログレスバーで表示
- Week 0 → Week 2 → Week 4 の変化を時系列で表示

#### リンクセクション
- SNS（X, LinkedIn等）
- GitHub / 個人サイト
- メールアドレス（公開範囲設定付き）

---

### 5. 参加者一覧ページ

- カード形式のグリッドレイアウト
- 各カードに: 顔写真、氏名、所属大学・学年、興味分野タグ、スキルタグ、一言抜粋、就職興味度
- 検索バー + フィルタ（分野 / スキル / 就職興味度）
- 登録人数の表示
- ページネーション

---

### 6. 企業ダッシュボード

- 2カラムレイアウト
  - 左: ブックマークした参加者リスト（顔写真+名前+所属+専門+就職興味度）
  - 右: 新着参加者
- 下部: スキルタグ別の参加者分布（タグクラウド形式、人数付き）
- 「参加者一覧へ」ボタン

---

### 7. ログインページ

- 中央にカード型のログインフォーム
- 「AstroCamp 2026 ポートフォリオサイト」のタイトル
- Googleログインボタン（プライマリ）
- メール/パスワードログイン（セカンダリ）
- 「招待された方のみご利用いただけます」の注記

### 8. デザインの方向性

#### トーン&マナー
- **宇宙×テック×教育** の雰囲気
- プロフェッショナルだが堅すぎず、学生が親しみやすいデザイン
- 暗い宇宙的な背景（ダークモード基調）ではなく、**明るく清潔感のあるデザイン**を基本とする（企業の採用担当が見やすいように）
- アクセントカラーで宇宙感を演出（深い青、紫、または星空をイメージした色使い）

#### 参考にすべきサービス
- **Wantedly**: プロフィールカードのレイアウト、「やりたいこと」の見せ方
- **LAPRAS**: スキルタグの表示方法、技術者ポートフォリオのUI
- **LinkedIn**: 経歴タイムライン、推薦・スキルのエンドースメント表示
- **BaseMe**: 価値観ベースのマッチングUI（参考: Z世代向けキャリアプラットフォーム）
- **学会ポートフォリオ**: アカデミック要素の見せ方

#### レスポンシブ対応
- デスクトップ（企業担当者の主要閲覧環境）
- モバイル（参加者の主要編集環境）

#### アクセシビリティ
- コントラスト比の確保
- タグの視認性（色だけに依存しない）

### 9. 特に力を入れてほしいデザインポイント

1. **Before/After表示**: 参加前の意気込みと参加後の心境変化の並列表示。このサイト最大の差別化ポイント。成長のストーリーが一目で伝わるビジュアル表現を工夫してほしい。

2. **スキル成長の可視化**: 時系列でのスキル変化をグラフ/チャートで魅力的に表示。Week 0 → Week 4 の成長カーブが直感的にわかるデザイン。

3. **企業視点での参加者発見体験**: 企業担当者が「この学生と話してみたい」と思えるカード一覧のデザイン。就職興味度・専門分野でのフィルタリングがスムーズなUI。

4. **学生プロフィールカード（名刺代替）**: サイト内のプロフィールとは別に、展示会等で配布する物理的なプロフィールカードのデザインも作成してほしい。QRコードからポートフォリオサイトの個人ページに飛べる設計。表面: 氏名・大学・専門・一芸アピール、裏面: QRコード・連絡先。

---

### 10. 追加コンテキスト：宇宙スキル標準との連携可能性

内閣府が策定した「宇宙スキル標準」の枠組みをポートフォリオサイトに取り入れることを検討中です。以下の要素をスキル表示に反映できるようにしておいてください：

- **スキル分類**: ベーシック・マネジメント・テクニカルの3カテゴリ
- **評価体系**: 4軸 × 5段階の20区分評価（単純な5段階評価ではない）
- **業務とスキルの2軸**: 業務区分とスキル区分の対応関係の可視化

これらは将来的にスキルタグやレーダーチャートの構造に反映する予定です。現段階では、スキル表示部分のデザインに拡張性を持たせておいてください。

### 11. 技術的制約（参考情報）

- ホスティング: Vercel / Netlify + Supabase（想定）
- 認証: Google OAuth + メール/パスワード
- 予算: 無料枠中心、最小限のコスト
- 開発者: 少人数（1〜2名）のため、シンプルなコンポーネント設計が望ましい
- フレームワーク: Next.js / React を想定
